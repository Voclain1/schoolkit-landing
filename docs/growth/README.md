# Growth kit: first 90 days

Ready-to-use materials for the 90-day plan in the growth strategy doc. The code
side (pages, tools, tracking) is already in the repo. Everything here is a task a
person has to do: claim a profile, send an email, ask a school.

| Week | Task | Material | Owner |
| --- | --- | --- | --- |
| 1 | Verify Search Console and Bing Webmaster Tools, submit `/sitemap.xml` | [setup-checklist.md](setup-checklist.md) | Founder |
| 1 | Fix the "live" vs "early access" message and the stale "billing starts September 2026" line | [setup-checklist.md](setup-checklist.md) | Founder |
| 1–2 | Run the 25 AI prompts once as a baseline | [ai-prompt-tracker.csv](ai-prompt-tracker.csv) | Founder |
| 2–4 | Claim and complete directory and review profiles | [brand-fact-sheet.md](brand-fact-sheet.md), [setup-checklist.md](setup-checklist.md) | Founder |
| 2–4 | Brief two freelance writers | [writer-brief.md](writer-brief.md), [editorial-calendar.md](editorial-calendar.md) | Founder |
| 3–6 | Pitch the roundup authors | [outreach-roundups.md](outreach-roundups.md) | Founder |
| 6–10 | Ask live schools for reviews; draft case studies | [review-and-case-study-requests.md](review-and-case-study-requests.md) | Founder |
| 8–12 | Send the State of Nigerian Private Schools survey | [school-survey.md](school-survey.md) | Founder |
| 8–12 | Contact NAPPS chapters and partners | [outreach-partners-and-press.md](outreach-partners-and-press.md) | Founder |
| 12 | First monthly review against Gate 1 | [ai-prompt-tracker.csv](ai-prompt-tracker.csv), Search Console | Founder |

Rules that apply to every item: describe only features marked "Live now" on the
homepage, never buy links or reviews, and never put student data in marketing.
